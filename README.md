# series-homework
פרויקט תרגול לעבודה עם נתוני סדרות, גישה לנתונים ופונקציות על מערכים 

# How to run the check
כדי להריץ את הבדיקה נריץ בטרמינל:
node check.js

# 1. addEpisode
בפונקציה להוספת פרק יצרתי מחדש ארבעה דברים: סדרה חדשה, מערך עונות חדש, עונה חדשה ומערך פרקים חדש.
.לא מספיק ליצור עותק של הסדרה בלבד, כי ההעתקה היא שטחית
.הפונקציה יוצרת אובייקט חדש, אבל העונות והפרקים שבתוכו נשארים אותם מערכים ואובייקטים של המקור, לכן כל שכבה שמשתנה צריכה להיווצר מחדש, וכך המקור לא נפגע


# 2. Bug 3
.בתקלה מספר 3 העמית אכן יצר עותק, אבל העותק לא עזר, מערך העונות בעותק המשיך להצביע על אותו מערך עונות של הסדרה המקורית
בנוסף, הפרק נוסף בפעולה שמוסיפה איבר לסוף מערך קיים, והיא משנה את המערך עצמו ולא יוצרת מערך חדש. לכן הפרק נוסף גם לסדרה המקורית, והעותק לא הגן עליה.
